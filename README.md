# .github

This is the ConnectBot organization's `.github` repository, which holds shared GitHub configuration and organization profile content:

- [profile/README.md](profile/README.md) provides the introduction shown on the organization's GitHub profile.
- [FUNDING.yml](FUNDING.yml) lists sponsorship options.
- [.github/chainguard/](.github/chainguard/) contains trust policies for release automation across ConnectBot projects.

GitHub also uses an organization's `.github` repository to provide default community health files, such as contributing guidelines and issue or pull request templates, for repositories that do not define their own. See GitHub's documentation on [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) and [customizing an organization's profile](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).
